Code for paper "Calibrating Perception Uncertainty for Autonomous Driving" by Markus Kängsepp


Notebooks should cover main methodology of the paper:
1) "F - Figure - segmentation to inputs" - has code to generate Figure about inputs
2) "Fiery - Figures" - all calibration figures generated for the paper and poster, 
		       all necessary data for these figures also included
3) "FIERY - Location uncertainty", 
   "FIERY - Presence uncertainty", 
   "FIERY - Undetected object uncertainty" and
   "FIERY - Trajectory" - notebooks have code needed for generating these uncertainties used for "Fiery - Figures"
                        - data for these notebooks are not included.


Code:

helper.py - includes helper functions used in notebooks
binnings.py - has calibration and ECE and reliability diagram functions


Results NPZ:

Different result files needed for "Fiery - Figures" notebook.
